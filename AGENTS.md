# Repository working agreement

- Requested repository work is not complete while it exists only in a local or transient workspace.
- Unless the user explicitly requests another destination, finish validated changes by committing and pushing them directly to GitHub `main`.
- Verify that remote `main` contains the resulting commit and that the GitHub Pages deployment has started.
- Do not create branches or pull requests unless the user explicitly asks for them.
- Never leave completed work solely in scratch storage.
- Before updating `main`, confirm the remote head has not moved and preserve unrelated changes.
- If normal Git authentication fails, immediately use the connected GitHub integration rather than stopping at a local commit.
